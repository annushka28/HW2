# Система управления рецептами

Проект реализует консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", масштабировать порции и генерировать список покупок.

## Установка

```bash
git clone https://github.com/annushka28/HW2.git
cd HW2
pip install -r requirements.txt
```

## Использование

Классы находятся в файле main.py.
Для запуска тестов выполнить:
```bash
pytest
```
